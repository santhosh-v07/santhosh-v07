<details>
<summary>How this profile stays current</summary>

Every SVG is rendered by my own service from public GitHub records. Names, bio, repository details, languages, counts, and contribution dates are fetched dynamically. Each panel shows its fetch time, and the underlying records are available through **Data behind the visuals** above.

- **Activity:** the same anonymous contribution calendar available on my public GitHub profile. Orbit bars show weekly totals; the line chart shows daily counts. Streaks use consecutive active UTC dates within the displayed year.
- **Languages:** actual code-byte shares in owned, non-fork public repositories, including all repository pages. These percentages describe the code, not skill proficiency.
- **Projects:** a curated selection of real public repositories, with their current metadata and latest default-branch commits.
- **Refresh:** the service reuses fetched data for at most 60 seconds and requests image revalidation. The live view requests refreshed panels every 60 seconds while visible. GitHub's own activity processing and README image caching can add delays; an open README cannot continuously fetch new data.
- **Motion:** animations loop over the fetched records. They do not invent events, increase counts, or claim that I am online. Unavailable data is reported explicitly.

</details>
